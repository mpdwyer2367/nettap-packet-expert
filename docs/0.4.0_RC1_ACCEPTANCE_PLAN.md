# NetTAP Network Intelligence 0.4.0-rc.1 acceptance plan

## Scope

Qualify the exact signed `0.4.0-rc.1` source package on clean macOS and Windows/WSL2 hosts. Confirm that the promoted Qwen3.5 9B Q4_K_M base, one shared NetTAP model, two managed Open WebUI profiles, offline RAG and the Evidence Workspace operate within the documented boundaries.

## Required gates

1. Verify source archive digest, signature, commit, tree and provenance.
2. Verify the pulled base is exactly `qwen3.5:9b-q4_K_M` with Ollama ID `6488c96fa5fa`.
3. Verify `nettap-ai:0.4.0-rc.1` is created and both managed profiles select it.
4. Run all behavior, profile-isolation, offline RAG and normalized-ingestion tests.
5. Confirm raw evidence remains in the Evidence Workspace and reaches the LLM only as reviewed minimized context.
6. Measure one-model storage sharing, memory use and acceptable response latency on both target platforms.
7. Test restart, backup, restore, failed-update recovery and rollback to the previously approved package.
8. Produce and review SBOM/CVE, penetration-test, legal/licensing, support and commercial-acceptance evidence.

## Commands

```bash
./tests/clean-package-acceptance.sh \
  --archive /approved/nettap-ai-suite-0.4.0-rc.1-source.tar.gz \
  --evidence-dir /protected/nettap-040rc1-acceptance \
  --public-key /approved/cosign.pub
```

Run once on each supported target using the identical signed package, then compare summaries with `./tests/compare-platform-acceptance.sh`.

## Decision rule

Any missing, mismatched or failing gate leaves the release at evaluation-only status. Source-level promotion of Qwen3.5 9B is not a substitute for exact-build runtime or authorized release acceptance.
