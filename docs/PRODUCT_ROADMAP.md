# Product roadmap

## RC7 — unified application candidate

- One authenticated Open WebUI and combined assistant
- One shared Qwen2.5 7B base and one versioned `nettap-ai` model
- Pinned offline RAG with shared, visibility and packet-analysis knowledge
- Chat attachment Filter and internal deterministic evidence service
- Classic PCAP, structured JSON/JSONL and line-log ingestion with explicit limits
- Generated administrator activation, backup/restore and release controls

Exit requires exact-commit macOS and Windows/WSL2 acceptance, representative attachment analysis, restart/backup/restore/rollback, SBOM/CVE and penetration-test dispositions, signed artifacts and authorized commercial approval.

## 0.4 — hardened evidence operations

- PCAPNG and validated binary IPFIX/NetFlow/sFlow decoders
- Sandboxed TShark extraction where licensing and distribution permit
- Case-level RBAC, retention/legal hold and encrypted-storage policy
- Exportable professional reports and customer-controlled threat-intelligence enrichment
- Parser fuzzing, adversarial file tests and performance limits

## 0.5 — NetTAP visibility connectors

- Least-privilege IPFIX, syslog TLS, SNMPv3, gNMI, REST, webhook and file collectors
- Exporter identity, template state, sampling, time quality, observation point and schema provenance
- Back-pressure, deduplication, health, secret rotation and tenant isolation
- Read-only normalized retrieval; raw payloads remain outside the LLM by default

## 1.0 — commercial software appliance

- Signed installer/update/rollback channel and supported-host matrix
- OIDC/SAML/MFA, immutable audit export and customer SIEM integration
- Entitlement/licensing service with offline policy
- Capacity tiers, support bundle, SLA/escalation, vulnerability response and recovery objectives
- Reproducible AMD64/ARM64 packaging validated only on advertised hypervisors

An OVA is a separate distribution and certification scope. Do not claim VirtualBox/VMware/Apple Silicon compatibility until the exact artifact passes those platform tests.
