# Security policy

Please report suspected vulnerabilities privately through GitHub's **Security > Advisories > New draft security advisory** workflow. Do not include secrets, production packet captures, customer identifiers, or exploit details in public issues.

Version `0.4.0-rc.1` has production-hardening and profile-isolation controls but has not completed production or commercial certification. See [the security boundary](docs/SECURITY.md), [threat model](docs/THREAT_MODEL.md), and [release gates](docs/COMMERCIAL_RELEASE_GATES.md).
