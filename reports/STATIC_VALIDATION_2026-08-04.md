# Historical RC7 static validation report — 2026-08-04

> This is a historical record for `0.1.0-rc.7`. It is not the current RC8 validation status. See `docs/VALIDATION_STATUS.md` and `reports/PUBLIC_COLLEAGUE_READINESS_2026-08-04.md`.

## Scope

NetTAP Packet Expert `0.1.0-rc.7`, standalone macOS Docker deployment source.

## Passed in the build workspace

- All Bash entry points pass `bash -n` syntax validation.
- Scripts avoid `mapfile`, which is unavailable in the Bash 3.2 supplied with macOS.
- `compose.yaml` parses as YAML and declares the required Ollama, model-initialization, and Open WebUI services.
- The fresh-install path explicitly pulls `qwen2.5:7b-instruct-q4_K_M` before creating the custom model.
- The UI binds to `127.0.0.1` by default.
- Ollama is not published to a host port.
- The backend network is internal; Ollama has a separate egress path for the declared model download.
- Authentication is enabled, later users default to pending, and password validation is enabled.
- Code execution, code interpreter, and automatic package installation are disabled.
- Four broad prompt suggestions replace the earlier packet-heavy quick actions.
- Source scanning found no private keys or GitHub token patterns.
- The repository excludes `.env`, packet captures, evidence, reports generated by tests, and macOS metadata.
- The assistant prompt explicitly separates observed facts, hypotheses, and unavailable data.

## Independently verified upstream facts

- Qwen2.5-7B-Instruct is Apache-2.0 licensed and the selected Ollama quantization is approximately 4.7 GB.
- Ollama is MIT licensed.
- Open WebUI's current license restricts removing or replacing its branding outside stated exceptions; this project retains Open WebUI branding.
- Open WebUI documents `DEFAULT_PROMPT_SUGGESTIONS`, `DEFAULT_MODELS`, first-user administrator behavior, pending later users, and persistent `WEBUI_SECRET_KEY` use.

## Not executed in this workspace

- Docker Compose semantic rendering, image pull, container startup, and model inference: Docker is unavailable.
- macOS deployment: the workspace host is Linux/x86_64, not macOS.
- ShellCheck: not installed in the workspace.
- Apple silicon and Intel Mac performance tests.
- Manual Open WebUI administrator creation, logout/login, model selection, and starter-prompt inspection.
- Image digest capture, SBOM generation, vulnerability scanning, signing, and production release approval.

## Release decision

Static source gate: **PASS**.

macOS runtime gate: **NOT RUN**.

Public release gate: **BLOCKED** until the macOS E2E script and manual checklist pass and an approved license is selected for NetTAP-authored source.
