# Support policy

`0.3.0-rc.4` is an integration release candidate and has no production SLA in this repository. Commercial support, response times, supported host versions, upgrade windows, vulnerability remediation targets, data-recovery objectives, and end-of-life dates must be approved before customer sale.

For evaluation defects, open a GitHub issue containing only reproducible non-sensitive information: exact version/commit, host and Docker versions, redacted command output, expected behavior, and actual behavior. Never attach credentials, `.env`, private keys, customer identifiers, chats, packet captures, telemetry payloads, backups, or forensic evidence.

Security reports use a private GitHub security advisory as described in [SECURITY.md](SECURITY.md).
